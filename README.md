Project Overview
This project is a simple introductory Flutter application created for Lab 1. It features a custom theme, personalized text, and screen width measurement using `debugPrint`.

 

 What I Learned & What Blocked Me;

  What I Learned:
- This was my  very first time  using Flutter and Dart. I learned how Flutter uses widgets (`Scaffold`, `Column`, `Text`) to build user interfaces.
- I discovered how useful Hot Reload (`r`) is for testing changes instantly without restarting the application.
- I learned how state management works with `StatefulWidget` and counters.

 What Blocked Me:
- The biggest challenges were related to environment configuration and native build tools. 
- I faced Gradle file locks (`dirty-sources.txt`) and missing Android SDK packages that failed to download via the command line due to network issues (Premature EOF). 
- Resolving these required installing the required SDK platforms manually through Android Studio and troubleshooting build errors, which taught me a lot about managing mobile development environments.
